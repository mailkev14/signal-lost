# Signal Lost v0.3.0 — Cinematic Interface Pass

- Animated orbital station and telemetry signals on the home screen.
- Live mission telemetry strip showing current sector and signal status.
- Interactive console hover/focus feedback and more immersive lighting.
- Animated result and event feedback.
- Narrow-screen layouts and reduced-motion accessibility support.
- No changes to server-side puzzle validation, private intel, or multiplayer protocol.

## OpenAI integration
The existing optional OpenAI-generated opening briefing remains in place. An adaptive AI mission director is **not** implemented in this version. AI briefings require server-side `ENABLE_AI_BRIEFINGS=true` and `OPENAI_API_KEY`. The standalone training demo never calls OpenAI.
